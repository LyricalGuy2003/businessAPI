--------------------------------------------------------------------------------
WHAT IS TRADENET?
--------------------------------------------------------------------------------

TradeNet is a trade licensing platform - think of it like a government portal where:
  - Business Traders    : register their businesses and apply for licenses
  - Trade Officers      : verify documents and approve/reject applications
  - Program Managers    : create trade programs and approve subsidies
  - Compliance Officers : investigate complaints and flag violations
  - Government Auditors : audit businesses and generate reports
  - Admins              : manage all users and monitor the system

STEP 4 - GUARDS (SECURITY BOUNCERS)
--------------------------------------------------------------------------------

File: TradeNet-Frontend/src/app/core/guards/auth.guard.ts

  export const authGuard: CanActivateFn = () => {
    const auth   = inject(AuthService);
    const router = inject(Router);

    if (auth.isLoggedIn()) {
      return true;                              // allow access
    }
    return router.createUrlTree(['/login']);    // kick to login page
  };

  export const roleGuard = (allowedRoles: string[]): CanActivateFn => () => {
    const auth   = inject(AuthService);
    const router = inject(Router);

    if (allowedRoles.includes(auth.role()!)) {
      return true;                              // your role is in the allowed list
    }
    return router.createUrlTree(['/login']);    // wrong role, kick out
  };

  export const guestGuard: CanActivateFn = () => {
    const auth   = inject(AuthService);
    const router = inject(Router);

    if (!auth.isLoggedIn()) {
      return true;                              // not logged in, can see login page
    }
    const roleRoutes: Record<string, string> = {
      SystemAdmin:    '/admin/dashboard',
      BusinessTrader: '/business-trader/dashboard',
      ...
    };
    return router.createUrlTree([roleRoutes[auth.role()!]]);
  };

  - inject(AuthService)
      Gets the auth service which knows if you're logged in.

  - auth.isLoggedIn()
      Checks if a JWT token exists in localStorage.

  - auth.role()
      Reads your role from the saved token data.

  - router.createUrlTree(['/login'])
      Creates a redirect instruction to the login page.

STEP 6 - BACKEND RECEIVES REGISTRATION
--------------------------------------------------------------------------------

File: TradeNet/TradeNet.Admin.API/Controllers/AuthController.cs

  [HttpPost("register")]
  public async Task<IActionResult> Register([FromBody] RegisterRequest request)
  {
      // 1. Check if email already exists
      var existing = await _userRepo.GetByEmailAsync(request.Email);
      if (existing != null)
          return BadRequest(new { message = "Email already registered" });

      // 2. Force role to BusinessTrader (only admins can create other roles)
      request.Role = "BusinessTrader";

      // 3. Hash the password (never store plain text!)
      var hashedPassword = BCrypt.Net.BCrypt.HashPassword(request.Password);

      // 4. Create the User object
      var user = new User {
          FullName  = request.FullName,
          Email     = request.Email,
          Password  = hashedPassword,
          Role      = request.Role,
          Phone     = request.Phone,
          Status    = "Active",
          CreatedAt = DateTime.UtcNow
      };

      // 5. Save to database
      await _userRepo.CreateAsync(user);

      // 6. Also create a BusinessTrader profile linked to this user
      var trader = new BusinessTrader {
          UserId             = user.Id,
          FullName           = user.FullName,
          Email              = user.Email,
          VerificationStatus = "Pending"
      };
      await _traderRepo.CreateAsync(trader);

      return Ok(new { message = "Registration successful" });
  }

  - [HttpPost("register")]
      This method handles POST requests to /api/auth/register.

  - [FromBody]
      Reads the JSON from the request body into the request object.

  - BCrypt.HashPassword(...)
      Converts "password123" into a scrambled string like "$2a$10$xyz..."
      Even if hackers steal the database they cannot read the password.

  - await _userRepo.CreateAsync(user)
      Tells the repository to save the user to the database.

  Two records are created:
      One in the Users table, and one in the BusinessTraders table.

STEP 8 - USER LOGS IN
--------------------------------------------------------------------------------

Frontend sends login request (auth.service.ts):

  login(req: LoginRequest): Observable<AuthResponse> {
    return this.http.post<AuthResponse>(
      'https://localhost:7001/api/auth/login',
      req
    ).pipe(
      tap(response => {
        localStorage.setItem('tnet_user', JSON.stringify(response));
        this._user.set(response);
      })
    );
  }

  - tap(response => ...)
      "Peek" at the response before passing it along, used here to save it.

  - localStorage.setItem(...)
      Saves to browser storage so you stay logged in even after page refresh.

  - this._user.set(response)
      Angular signal: updates reactive state so all components instantly
      know you are logged in.

Backend validates login (AuthController.cs):

  [HttpPost("login")]
  public async Task<IActionResult> Login([FromBody] LoginRequest request)
  {
      // 1. Find user by email
      var user = await _userRepo.GetByEmailAsync(request.Email);
      if (user == null || !BCrypt.Verify(request.Password, user.Password))
          return Unauthorized(new { message = "Invalid credentials" });

      // 2. Check user isn't suspended
      if (user.Status != "Active")
          return Unauthorized(new { message = "Account is deactivated" });

      // 3. Build JWT token
      var tokenHandler    = new JwtSecurityTokenHandler();
      var key             = Encoding.ASCII.GetBytes(_config["Jwt:Key"]!);
      var tokenDescriptor = new SecurityTokenDescriptor {
          Subject = new ClaimsIdentity(new[] {
              new Claim("userId",          user.Id.ToString()),
              new Claim(ClaimTypes.Email,  user.Email),
              new Claim(ClaimTypes.Role,   user.Role),
              new Claim("fullName",        user.FullName),
          }),
          Expires            = DateTime.UtcNow.AddHours(8),
          SigningCredentials = new SigningCredentials(
              new SymmetricSecurityKey(key),
              SecurityAlgorithms.HmacSha256Signature
          )
      };
      var token = tokenHandler.CreateToken(tokenDescriptor);

      // 4. Log the login action
      await _logRepo.CreateAsync(new SystemLog {
          UserId = user.Id, Action = "Login", Resource = "Auth"
      });

      // 5. Return everything the frontend needs
      return Ok(new AuthResponse {
          Token    = tokenHandler.WriteToken(token),
          UserId   = user.Id,
          FullName = user.FullName,
          Email    = user.Email,
          Role     = user.Role
      });
  }

  - BCrypt.Verify(plain, hashed)
      Compares the typed password against the stored hash.
      Never decrypts, just checks if they match.

  - JWT (JSON Web Token)
      A digitally signed string like "eyJhb...".
      Contains your userId, email, role.
      The backend can verify it without checking the database every time.

  - Claims
      Pieces of information baked into the token: who you are, what role you have.

  - Expires = DateTime.UtcNow.AddHours(8)
      Token automatically expires in 8 hours.

  - HmacSha256Signature
      The digital signature algorithm that prevents tampering.

STEP 9 - JWT INTERCEPTOR (AUTOMATIC TOKEN ATTACHMENT)
--------------------------------------------------------------------------------

File: TradeNet-Frontend/src/app/core/interceptors/jwt.interceptor.ts

  export const jwtInterceptor: HttpInterceptorFn = (req, next) => {
    const auth = inject(AuthService);

    if (req.url.includes('/auth/')) {
      return next(req);   // skip token for login/register
    }

    const token  = auth.token();
    const userId = auth.userId();

    if (token) {
      const authReq = req.clone({
        setHeaders: {
          'Authorization': `Bearer ${token}`,
          'X-User-Id':     userId?.toString() ?? ''
        }
      });
      return next(authReq);
    }

    return next(req);
  };

  - Interceptor
      Sits between your service and the HTTP call, like a checkpoint.

  - req.clone(...)
      HTTP requests are immutable, so you make a copy with new headers added.

  - Authorization: Bearer {token}
      Standard HTTP auth header. The backend reads this to know who you are.

  - X-User-Id
      Custom header so the backend knows your userId without decoding
      the full token.

STEP 10 - BACKEND VERIFIES THE JWT ON PROTECTED ROUTES
--------------------------------------------------------------------------------

In each API's Program.cs:

  builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
      .AddJwtBearer(options => {
          options.TokenValidationParameters = new TokenValidationParameters {
              ValidateIssuerSigningKey = true,
              IssuerSigningKey        = new SymmetricSecurityKey(
                  Encoding.ASCII.GetBytes(builder.Configuration["Jwt:Key"]!)
              ),
              ValidateIssuer   = true,
              ValidIssuer      = "TradeNetAPI",
              ValidateAudience = true,
              ValidAudience    = "TradeNetClients",
          };
      });

  app.UseAuthentication();  // "who are you?"
  app.UseAuthorization();   // "are you allowed to do this?"

  - AddJwtBearer
      Registers JWT validation middleware.

  - IssuerSigningKey
      Uses the same secret key to verify the token was not tampered with.

  - UseAuthentication()
      Reads the Authorization header and decodes the token.

  - UseAuthorization()
      Checks if the decoded user has permission.

Controllers use:

  [Authorize(Roles = "SystemAdmin")]  // only Admins can call these endpoints
  [ApiController]
  [Route("api/admin")]
  public class AdminController : ControllerBase { ... }

  - [Authorize(Roles = "SystemAdmin")]
      If your JWT does not have role = SystemAdmin, you get 403 Forbidden.

       }

    6. await _context.SaveChangesAsync()
       -> SQL: INSERT INTO LicenseApplications (...) VALUES (...)
    7. Create Notification for the trader
    8. Return 200 OK
           |
           v
  Angular receives 200 OK -> shows "Application submitted successfully"

DATABASE TABLES SUMMARY
--------------------------------------------------------------------------------

  Users                  <- all accounts (any role)
  BusinessTraders        <- extra profile for trader users (1:1 with Users)
  Businesses             <- companies owned by traders (1:N with BusinessTraders)
  TraderDocuments        <- personal ID docs uploaded by traders
  BusinessDocuments      <- company docs (registration cert, etc.)
  TradeLicenses          <- available license types (created by admin/officer)
  LicenseApplications    <- trader's requests to get a license
  Transactions           <- financial transactions logged by traders
  TradePrograms          <- government programs (created by Program Manager)
  Subsidies              <- applications for financial aid from a program
  Resources              <- equipment/assets within a trade program
  ComplianceRecords      <- audit trail of compliance checks
  Complaints             <- complaints filed by traders
  Violations             <- violations recorded against businesses
  Audits                 <- formal government audits
  Reports                <- generated PDF/data reports
  Notifications          <- in-app alerts for each user
  SystemLogs             <- every login/action recorded for security

--------------------------------------------------------------------------------

  backend always knows WHO is asking and WHETHER they are allowed to do it.
